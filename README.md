# Motion Lab

A sandbox for motion-design experiments: easing studies, scroll behavior tests and
reference shots in vanilla HTML/CSS/JS — no framework, no build step.

Open `index.html` in a browser. Each experiment lives in its own folder under `css/`,
`js/` and `fonts/`. The `shots/` directory holds captured reference frames.

## Status

**Sandbox** — a lab, not a product. Techniques that prove out here graduate into
real builds (see [quality-house-v4](https://github.com/Moenabiel/quality-house-v4)
for where they landed).

## Stack

- Vanilla HTML/CSS/JS
- No dependencies, no build
